# Тестовые задания

Веб-разработчик и техническая поддержка сайтов: автоматизация в Google Sheets, кастомные шаблоны
для 1С-Битрикс, аудит сайтов и SMM-контент.

Три выполненных тестовых задания, которые можно открыть и посмотреть: исходный код и документы,
приложенные к решению.

репозиторий вынесены метод, структура работы и выводы по категориям. Домен, контакты, реквизиты,
имена, идентификаторы соцсетей и цены заказчика удалены — полная версия предъявляется по запросу.

## Стек

**Разработка и автоматизация**

- Google Apps Script (JavaScript), Google Sheets: `SpreadsheetApp`, `MailApp`, data validation,
  simple triggers `onEdit` / `onOpen`
- PHP, 1С-Битрикс: шаблоны компонентов, `result_modifier.php`, `$arResult`
- HTML, CSS: Grid, flexbox, адаптивность без медиазапросов
- Git, GitHub

**Аудит и маркетинг**

- Серверный HTML (`curl`), краул `sitemap.xml`, проверка HTTP-статусов и редиректов
- Chrome DevTools Protocol: TTFB, FCP, Load, вес HTML, разобранный DOM
- Schema.org и JSON-LD, Open Graph, Twitter Card, `canonical`, `robots.txt`
- Контент-маркетинг, рубрикатор, календарный план, кросспостинг, UTM-разметка
- Telegram, VK, MAX, Rutube

---

Все три задания выполнены по ТЗ заказчика и отправлены на отклик. В репозитории нет метрик
и цифр, которых нет в исходных файлах: только то, что реально сделано и измеримо в коде.

Контакты намеренно не указаны: они есть в профиле на rabota.by и на hh.ru. Ссылка на этот
репозиторий вставляется в отклик, а не наоборот.
