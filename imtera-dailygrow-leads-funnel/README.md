# ИМТЕРА (DailyGrow) — анализ воронки лидов: диагностика, план на 30 дней, реактивация и возражение «дорого»

Вакансия: **Интернет-маркетолог**, третье тестовое задание получено 07.10.2026, дедлайн 08.10 18:00. Ответ отправлен 07.10.2026 в 21:24 — за ~20 часов до дедлайна, с преимуществом за досрочность.

## Задание

Сценарий: выход на работу в DailyGrow три дня назад, доступ к CRM, данные по входящим заявкам на AI-анализ звонков за 30 дней (июль, 18 лидов). Требуется:

1. **Диагностика** — назвать одну корневую причину потерь в воронке и обосновать её в 3–5 предложениях.
2. **План на 30 дней** — первые четыре недели с логикой очереди шагов, максимум одна страница.
3. **Три реактивации** — выбрать три замороженных лида и написать для каждого первое сообщение с указанием, почему выбран именно он.
4. **Работа с возражением** — «дорого» (самое частое): живой текст ответа от первого лица для звонка и переписки.

## Что сделано в ответе

**Диагностика.** Корневая причина — воронка называет цену раньше, чем доказывает ценность, и не доводит до конца собственные обещания; середины воронки нет. «Дорого» — не причина отказа, а единственный аргумент клиента, когда больше не с чем сравнивать. Пять из семи замороженных лидов заморожены не клиентом, а нами: по Страховой Гарант не отправлено обещанное КП, по Клинике Здоровье Плюс КП повисло, по FitLife не нашлось кейсов, по Солнечному берегу и BonAppetit не отвечен технический вопрос по интеграции. Самый горячий источник (вх. звонки) дал худший результат: все три звонка потеряны с «дорого», потому что на входящем звонке клиент сразу просит цену, а ей отвечают без подготовки. Вывод: проблема не в цене и не в качестве лидов — цена лишь место, где отсутствие ценности становится заметно.

**План на 30 дней (логика, недели от 22.07).**
- Неделя 1 — закрыть собственные долги (невыполненные обещания) и собрать пакет доказательств: 2–3 кейса с цифрами, шаблон КП, лист совместимости с amoCRM/Битрикс. Сначала долги, потому что вернуть эти 7 лидов дешевле, чем греть новых, но идти к ним с пустыми руками бессмысленно.
- Неделя 2 — волна реактивации: персональные касания с конкретным поводом (кейс, КП, ответ по интеграции) по всем замороженным и двум молчунам; цель 9 касаний → 3–4 разговора → 1–2 сделки. Касание имеет смысл только когда есть что показать.
- Неделя 3 — пересобрать разговор о цене: правило «цена — только после расчёта» (три вопроса об объёме звонков и стоимости сделки, цена как доля от найденных потерь), пилот на одном отделе на две недели. Скрипт менять только когда за словами есть цифры.
- Неделя 4 — зафиксировать правила (обязательный следующий шаг, срок ответа, еженедельный разбор зависших, запрет называть цену без демо/расчёта) и пересмотреть источники: рекомендации у оплативших, качественная квалификация. Метрика месяца: 3–4 сделки, конверсия из заявки в оплату 11% → 25–30%, ноль лидов без назначенного следующего шага.

**Три реактивации.** Отбор по принципу: заморозка снимается нашим действием, а не ожиданием.
1. **Страховая Гарант** — самый свежий лид, заморожен целиком по нашей вине (сам просил индивидуальное КП, ждёт с 20.07); страховые — один из самых звонкоёмких бизнесов, максимальный чек. Сообщение: короткое извинение без оправданий, КП во вложении, предложение пересчитать цифры под объём за 15 минут, вопрос про созвон на неделе.
2. **Туроператор «Солнечный берег»** — единственные слова «хотим попробовать», один неснятый технический блокер по amoCRM, плюс реферал с оплаченным кредитом доверия. Сообщение: «дружим», интеграция по API за день, предложение теста на две недели на одном отделе с показом внутри amoCRM.
3. **Автосалон «Премиум Авто»** — цена уже принята («нормальная»), уперся в согласование с директором; две недели тишины = не «передумал», а отсутствие аргументов. Сообщение: предложение готовой записки на одну страницу на языке автосалона и опция прямого 10-минутного созвона с директором.

**Возражение «дорого».** Не спорить и не защищать цену — согласиться и взять вину за то, что назвал её без подготовки. Не сравнивать по прайсу (разная глубина подсчёта), а пересчитать на цифрах клиента: 5–8% звонков, где клиент был готов купить, но менеджер не дожал. Снять риск пилотом — две недели на одном отделе, без годового договора; если цифры не будут — сам первым скажет не покупать. В переписке — та же логика короче.
