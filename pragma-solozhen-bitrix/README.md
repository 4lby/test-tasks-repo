# Кастомный шаблон `bitrix:news.list` — «promo_cards»

Тестовое задание на вакансию «Специалист по сопровождению и доработке сайтов» (БУС) в
ООО «Прагма-Солюшен», Минск. Отклик на rabota.by от 27.08.2026, решение отправлено 01.09.2026.

## Суть задачи

Нужно было написать кастомный шаблон стандартного компонента 1С-Битрикс `bitrix:news.list`,
который выводит блок «Акции и спецпредложения» в виде адаптивной сетки карточек.

Логика, которую задал заказчик:

- если до окончания акции осталось **менее 3 дней** — карточка получает флаг «горящая»;
- если скидка **больше 20%** — бейдж «Суперцена», иначе «Выгода».

## Что сделано

Три файла шаблона в структуре размещения компонентов 1С-Битрикс:

| Файл | Назначение |
|---|---|
| `result_modifier.php` | Расчёт `IS_HOT` и `BADGE` до рендера шаблона |
| `template.php` | Разметка карточек, подключение CSS, экранирование вывода |
| `style.css` | Адаптивная сетка, бейджи, hover-эффекты |

Технические решения:

- `result_modifier.php` работает с сырым массивом `$arResult` до того, как шаблон его отрисует.
  Флаги считаются в одном месте, разметка остаётся чистой.
- Дата окончания акции разбирается через `MakeTimeStamp($ACTIVE_TO, 'DD.MM.YYYY HH:MI:SS')`,
  срок считается в днях до `time()`. Если `ACTIVE_TO` пуст или не распарсился, флаг не
  выставляется — карточка не ломается.
- Все значения, попадающие в HTML, экранируются `htmlspecialcharsbx()` — и название, и
  описание, и бейдж. `DISCOUNT_PERCENT` приводится к `(int)`, то есть свойство не может
  вывести в разметку произвольную строку.
- Пустой результат обрабатывается ранним `return` — вместо пустой сетки с отступами не
  рендерится ничего.
- В шаблоне есть проверка на наличие картинки, названия, описания и скидки: карточка не
  разваливается, если часть полей не заполнена.
- Изображения грузятся лениво (`loading="lazy"`), высота картинки фиксирована через
  `object-fit: cover`, чтобы сетка не прыгала при загрузке.
- CSS: `grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))` — адаптивность
  средствами сетки, без медиазапросов.

## Требования к инфоблоку

| Свойство | Тип | Назначение |
|---|---|---|
| `DATE_ACTIVE_TO` (поле `ACTIVE_TO` элемента) | дата | Дата окончания акции, признак «горящей» карточки |
| `DISCOUNT_PERCENT` | число | Процент скидки, выводится в карточке, влияет на бейдж |
| `BADGE` | строка | Метка карточки |

## Подключение

Папку `local/templates/.default/components/bitrix/news.list/promo_cards` скопировать в корень
сайта на 1С-Битрикс (структура повторяет стандартное размещение шаблонов компонентов).

```php
$APPLICATION->IncludeComponent(
    'bitrix:news.list',
    'promo_cards',
    [
        'IBLOCK_TYPE'   => 'content',
        'IBLOCK_ID'     => 1, // ID инфоблока с акциями
        'NEWS_COUNT'    => '8',
        'SORT_BY1'      => 'ACTIVE_FROM',
        'SORT_ORDER1'   => 'DESC',
        'FIELD_CODE'    => ['NAME', 'PREVIEW_TEXT', 'PREVIEW_PICTURE', 'ACTIVE_TO'],
        'PROPERTY_CODE' => ['DISCOUNT_PERCENT', 'BADGE'],
    ]
);
```
