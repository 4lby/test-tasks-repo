# Три кластера запросов и метатеги

**Оговорка по цифрам.** Частотности `!W` сняты **выборочно** и округлены до 5–10 единиц.
Порядок величин и структура кластеров при этом верны, но внутренняя очерёдность запросов
внутри кластеров может сдвинуться после полного пересъёма. Полный пересъём требует
закрытого доступа к Wordstat и делается Key Collector'ом одной выгрузкой — сама процедура
не меняет архитектуру, только приоритеты.

**Обозначения.** `!W` — точная частотность по Вордстату, регион Москва (213). Интент:
`C` — коммерческий (транзакционный), `C/I` — смешанный, `I` — информационный.

**Как определялась принадлежность к кластеру.** Кластеризация по топу, hard-метод,
порог 3–4. Не эвристикой по похожим словам: запросы, выдача по которым совпадает
более чем на 70%, объединяются в один кластер; расхождение выдачи менее 30% — разные
кластеры с разными конкурентами.

узлам — и масштабировать только после подтверждения роста.

## Метатеги

**Правила, по которым составлены.** Title — до 65–70 символов, главный запрос в прямом
вхождении ближе к началу, в конце бренд. Description — 150–180 символов, не повторяет Title,
содержит УТП и конкретику (ставка, сумма, срок, требуемые документы) и призыв к действию.
Коммерческие цифры при обезличивании исключены; в рабочей версии они взяты с проверяемого
сайта и **перед публикацией должны быть сверены с актуальными условиями** — устаревшая ставка
в Description хуже, чем её отсутствие.
