# Анализ конкурентов и матрица покрытия

## Выборка

Сайты, стабильно присутствующие в топ-10/топ-20 Яндекса по Москве по ядру ниши
(«автоломбард» / «займ под залог ПТС»). Проверка видимости — сервисы проверки видимости (аналоги Keys.so, Bukvarix, SpyWords);
структура — разбор `sitemap.xml`, а не только меню. Так видна реальная архитектура, а не
витрина.

| # | Конкурент (обезличено) | Архетип структуры | Объём |
|---|---|---|---|
| 1 | лидер с гео-разветвлённой структурой (домен с гео-суффиксом) | Гео-разветвлённая | Сотни URL |
| 2 | `услуговый конкурент А` | Услуговая (по типу залога и ТС) | 22 URL |
| 3 | конкурент Б («расширенный продукт») | Расширенный продукт | 25 URL |
| 4 | `аналогичные плоские домены` | Услуговая, плоская — ближайшие аналоги аудируемого сайта | 10–15 URL |
| 5 | `федеральный МФО-портал` | Федеральный МФО-портал: продукт + калькуляторы + большой блог | 100+ URL |
| 6 | Агрегаторы (подборки «ТОП-20 автоломбардов Москвы») | Листинги | — |

## Структура по каждому

### 1. Гео-разветвлённая модель — лидер по охвату

```
/
├── /pledge-pts/                       — займ под залог ПТС
├── /services/
│   ├── /avtolombardy-vozle-metro/     — ~80+ страниц: /krasnoselskaya/, /dinamo/,
│   │                                    /smolenskaya/, /kutuzovskaya/, /zhulebino/ …
│   └── /vyezdnoe-obsluzhivanie/
│       ├── /okrug/                    — 12 страниц: ЦАО, САО, СВАО, ВАО, ЮВАО,
│       │                                ЮАО, ЮЗАО, ЗАО, СЗАО, ЗелАО, НАО, ТАО
│       ├── /rajon/                    — 100+ страниц
│       ├── /gorod/                    — города области
│       └── /ulicy/                    — шоссе и улицы
└── /about/
    ├── /news/
    └── /articles/
```

**Что важно.** Лидер забрал всю длинную гео-семантику города: метро, округа, районы, улицы,
ближнее Подмосковье. Каждая страница закрывает низкочастотный, но горячий запрос вида
«автоломбард на Дмитровском шоссе». Плюс отдельные новости и статьи — под E-E-A-T и
информационный спрос.

### 2. Услуговая модель — разделение по предмету залога и типу ТС

```
/
├── /avtolombard/                      — общая услуга
├── /avtolombard-pod-pts/
├── /avtozalog/  /avtozajm/
├── /kredit-pod-zalog-pts/
├── /vzyat-kredit-pod-zalog-avto/
├── /credits/                          — каталог программ
│   ├── /dengi-pod-zalog-pts/  /dengi-pod-zalog-avto/
│   ├── /zajm-pod-zalog-pts/   /zajm-pod-zalog-avto/
│   ├── /pod-zalog-avto/
│   ├── /pod-avto-s-polzovaniem/       — с правом пользования
│   ├── /pod-zalog-spectehniki/
│   └── /pod-zalog-gruzovogo-avto/
├── /about/
│   ├── /faq/  /usloviya/  /requisites/  /sdat-masjinu/
└── /contacts/
```

**Что стоит взять.** Разделение по типу транспортного средства (спецтехника, грузовой) и по
форме залога («с правом пользования» против «со стоянкой»). **Минус:** те же синонимичные
дубли, что и на аудируемом сайте, плюс дублирование между корнем и `/credits/`.

### 3. Расширенный продукт

Отдельные разделы под смежные услуги: выкуп, перезалог, лизинг, торги. **Таких интентов нет
ни у кого из прямых конкурентов** — низкоконкурентная ниша, и перехват клиентов с них
реалистичен.

### 4. Услуговая плоская — ближайшие аналоги

10–15 URL, плоская структура без гео и без разделения по типам ТС. **Вывод:** аудируемый сайт
идёт по этой модели, но наполовину — шесть страниц из шести разложены по синонимам, то есть
фактически работающих коммерческих посадочных всего две.

## Главные выводы

**1. Все конкуренты держат минимум 6–10 коммерческих посадочных, разнесённых по смыслу,
а не по синонимам. У нас шесть страниц разнесены именно по синонимам — то есть фактически
их две.** Это и есть причина «страницы в топ-100, но целевые за топ-50»: релевантность
размазана, и поисковик не выбирает, что ранжировать.

**2. Лидер выдачи вырос за счёт гео-масштабирования внутри города. Эту ось не использует
никто из остальных** — значит, она ещё частично свободна.

**3. Ось «тип транспортного средства» закрыта у конкурентов, но не у нас. При этом текст
нашей главной её уже декларирует** — то есть услуга есть, страниц нет. Самый дешёвый рост.

**4. Смежные интенты (перезалог, выкуп, лизинг) есть только у одного конкурента** —
низкоконкурентная ниша.

**5. Никто из прямых конкурентов не сделал сильный информационный хаб.** Задел на
среднесрок, в том числе под требования к качеству контента в финансовой тематике.

**6. Блок доверия (условия, реквизиты, реестр, отзывы) есть у трёх из четырёх**, у нас
его нет при том, что тематика к нему предъявляет повышенные требования. Это не «хорошо бы»,
а блокирующий фактор для ядра.
