# Структура и правила реализации

## Принцип

Структура строится по трём пересекающимся осям:

- **Ось A — услуга / предмет залога.** ПТС, авто со стоянкой, авто с правом пользования,
  перезалог, выкуп.
- **Ось B — тип транспортного средства.** Легковой, грузовой, спецтехника, мото,
  коммерческий, водный.
- **Ось C — география.** Округ → метро → район или шоссе, города области.

**Почему гибрид, а не одна ось.** Одна ось не закрывает спрос. По «займ под залог ПТС»
конкурирует весь рынок, и быстро там первые позиции не взять. А вот «займ под залог грузового
автомобиля в конкретном округе» или «автоломбард у метро с конкретной станции» —
низкоконкурентные входы с живым спросом, которые дают позиции быстрее всего.

**Гибридность — не механическое умножение.** Если перемножить оси буквально, получится
(6 услуг × 6 типов ТС × 200 гео) — десятки тысяч пустых страниц. Оси комбинируются только
там, где кластеризация по топу подтверждает отдельный спрос и самостоятельную выдачу.

---

## Правило допуска страницы

Страница создаётся, **только если выполнены все три условия одновременно**:

1. Кластер по топу отделяется от соседних (расхождение выдачи более 30%).
2. Суммарная частотность `!W` кластера ≥ 30 по целевому региону.
3. Для неё есть что написать уникального: условия, суммы, требования, примеры выдач,
   особенности — то есть content difference, а не подстановка топонима.

Нарушение любого одного условия означает, что страница **не создаётся**. Это правило важнее
желания закрыть больше запросов: пустая страница размывает краулинговый бюджет и добавляет
шаблонный контент, который поисковик ценит ниже отсутствующей страницы.

## Правила реализации

| Правило | Решение |
|---|---|
| URL | Только строчные латинские буквы, дефис как разделитель, завершающий слеш. Старые адреса со знаками подчёркивания без слеша — 301 на новые |
| Уровень вложенности | Не более 3 кликов от главной до любой коммерческой страницы |
| Перелинковка | Сквозное меню услуг + блок «Другие программы» в подвале каждой посадочной + из гео-страниц ссылки на услуги и обратно |
| Хлебные крошки | На всех страницах, с микроразметкой BreadcrumbList |
| Микроразметка | Organization, LocalBusiness (офисы), FAQPage, AggregateRating, FinancialProduct |
| Уникальность шаблонных гео | Минимум 40% уникального текста: адрес ближайшего офиса, время выезда, ориентиры, примеры выданных займов по этому району |
| Контроль каннибализации | После внедрения — ежемесячная сверка в Вебмастере: одна страница — один кластер |

## Порядок работ

| Этап | Срок | Работы | Ожидаемый эффект |
|---|---|---|---|
| 0. Техбаза | 1-я неделя | Проверить склейку доменов; привести URL к единому формату; настроить BreadcrumbList, Organization, LocalBusiness | Устранение блокеров |
| 1. Консолидация дублей | 1–2-я неделя | 6 услуговых страниц → 2 усиленные, 301-редиректы, переработка Title и Description | **Самый быстрый рост** |
| 2. E-E-A-T | 2–3-я неделя | `/usloviya-zayma/`, `/dokumenty/`, `/faq/` с FAQPage, расширенные `/otzyvy/` | Критично для тематики |
| 3. Типы транспорта | 3–5-я неделя | Кластер 2: грузовой, спецтехника, коммерческий транспорт | Новый низкоконкурентный трафик |
| 4. Подстраницы ядра | 5–6-я неделя | Кластер 1: онлайн, без справок, плохая КИ | Снятие внутренней каннибализации |
| 5. Гео-пилот | 6–9-я неделя | Кластер 3: 12 округов + 10–15 станций метро + страница выезда | Быстрые позиции по НЧ |
| 6. Масштабирование гео | 3–4-й мес | Остальные станции, шоссе, города области | Основной объём длинного хвоста |
| 7. Работа с 221 гео-страницей | параллельно | Шаг 1 — проверить в Вебмастере, какие дают трафик. Шаг 2 — трафиковые оставить и докрутить уникальностью, нулевые с нулевым ссылочным закрыть в noindex, затем поэтапно склеить. Резко удалять нельзя | Снятие малоценного контента без просадки |

**Почему этап 2 раньше масштабирования.** В финансовой нитике к сайтам предъявляются
повышенные требования к качеству контента и прозрачности. Без блока доверия — условий,
реквизитов, сведений о лицензии, реальных отзывов — структура сама по себе в топ ядро
не выведет. Масштабировать гео поверх непроверенного доверия — значит масштабировать
проблему.

**Почему этап 7 параллельно, а не в конце.** Шаблонные гео-страницы уже сейчас тянут вниз
хостовые факторы и размывают бюджет краулинга. Но резкое удаление может обрушить и без того
слабый траст, поэтому шаги выполняются по результатам проверки в Вебмастере, а не одним
решением.

## Измерение результата

- Снятие позиций раз в неделю по всем трём кластерам (регион и поисковики как в задании).
- Доля запросов в топ-10 и топ-30.
- Рост небрендового органического трафика.
- Количество заявок из органики по цели «Отправка формы».
- Стоимость заявки из органики в сравнении с контекстом.

## Риски

| Риск | Вероятность | Что делается |
|---|---|---|
| Просадка после склейки страниц | средняя | Склеивать на самую сильную по текущим позициям страницу, 301 (не 302), старые тексты перенести в новую, следить за переиндексацией в Вебмастере |
| Шаблонные гео попадут под фильтр | высокая, если делать в лоб | Пилот 10–15 страниц, не меньше 40% уникального блока, запуск волнами, контроль раздела «Страницы в поиске» |
| Финансовая тематика: сайт не проходит по доверию | высокая | Этап 2 вынесен до масштабирования: реестр, реквизиты, условия договора, реальные отзывы, фото офиса и команды |
| Каннибализация вернётся на новых подстраницах | средняя | Проверка кластеризацией по топу перед созданием каждой страницы; после — ежемесячная сверка «страница ↔ запрос» в Вебмастере |
| Частотности окажутся неточными | средняя | Полный пересъём `!W` до старта: структура от этого не меняется, меняется очерёдность работ |

## Первое действие, которое блокирует всё остальное

**В задании был указан один домен, фактически контент отдавался с другого.** Прежде чем
запускать любые работы, нужно проверить, что это 301-редирект, а не два индексируемых
зеркала. При двух зеркалах половина работ (консолидация дублей, перелинковка, сбор ссылок)
делается впустую, потому что авторитет и ссылочная масса размываются между адресами.
