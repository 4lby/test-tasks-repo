# Аудит сайта и SMM-стратегия для юридической фирмы

Тестовое задание на вакансию «Контент менеджер / SMM менеджер» (удалённо). Выполнено 28.09.2026.

## Что важно про этот файл

Тестовое задание выполнялось на реальном клиентском сайте. Поэтому в публичную версию
вынесены **метод, структура работы и выводы по категориям**, а не данные заказчика.

Убрано: домен, контакты, реквизиты, имена и должности, ссылки и идентификаторы соцсетей,
цены заказчика, имена его клиентов из кейсов, критика юридической структуры компании.
Ничего из перечисленного не восстанавливается из остальных файлов репозитория.

Полная версия аудита и контент-плана на 28 дней предъявляется по запросу — в исходном виде,
собственнику вакансии.

## Задача

Требовалось: провести аудит сайта юридической компании и подготовить контент-план для соцсетей
на месяц вперёд. Входных данных на старте не было: доступов к соцсетям и аналитике нет,
работа велась по публичной части сайта.

## Что сделано

### 1. Технический аудит сайта

Метод: разбор отданного сервером HTML (`curl`), краул всех URL из `sitemap.xml` (все страницы
отдавали 200), замеры в браузере через CDP на десктопном viewport, ручная проверка
микроразметки, веб-поиск по коммерческим запросам.

Стек сайта определён по отдаваемому коду: CMS на PHP с собственным шаблоном и модульной
структурой. Название системы в публичной версии не приводится, чтобы объект аудита не
идентифицировался по стеку.

Что проверялось и какие категории находок дало (сами находки обезличены):

| Категория | Что проверял | Типовые находки в этом проекте |
|---|---|---|
| Ссылки и превью | `og:image`, `og:site_name`, `og:locale`, Twitter Card, домен в ссылках соцсетей | `og:image` задан относительным путём — соцсети не резолвят, ссылки уходят без картинки; в описаниях соцсетей домен не тот, что у сайта |
| Индексация | `robots.txt`, код 404, `noindex` на 404, `canonical` | настоящий 404, но `canonical` на 404 ведёт на себя |
| Микроразметка | `JSON-LD` организации, `Service` / `Offer` / `BreadcrumbList`, `FAQPage` | один блок типа организации на весь сайт вместо разметки на страницах услуг; `FAQPage` есть не везде |
| Заголовки | `H1` / `H2` / `H3`, длины `title` и `description` | один `H1` на страницу (плюс), но `H1` без коммерческих слов; длинные `title` обрезаются в выдаче |
| Скорость | TTFB, FCP, Load, вес HTML, размер DOM, число запросов | быстрый сервер, но тяжёлый DOM: Load более 5 с, разобранный DOM на мегабайты, мегаменю продублирован в разметке несколько раз |
| Безопасность | HSTS, X-Frame-Options, nosniff, CSP | базовые заголовки настроены, CSP и Referrer-Policy отсутствуют |
| Шаблон | неотрендеренные плейсхолдеры, `meta keywords`, дубль `<style>` | неотрендеренный плейсхолдер региона попадает в `<title>` логотипа и в сниппет |
| Формы и CTA | формы, дубли кнопок, мессенджеры | одна форма без поля «суть вопроса», больше десяти дублей одной кнопки с `href="#"`; нет ни одного мессенджера, который в этом сегменте даёт основной поток заявок |
| Контентная база | глубина страниц услуг, отзывы, кейсы по судебным делам | сильный актив: глубокие страницы услуг и карточки конкретных судебных дел из открытого реестра — почти не используются в соцсетях |

Плюсы, которые зафиксированы отдельно, чтобы аудит не выглядел односторонним: все URL живы,
редиректы и базовые заголовки безопасности настроены, `canonical` присутствует, дисциплина
`H1` хорошая, микроразметка FAQ на главной корректная, цены по одной услуге расписаны честно.

### 2. Состояние соцсетей

Проверено по публичным превью, без входа в аккаунты. Картина: каналы существуют, но наполнения
нет — один канал создан и пуст, у группы единицы постов и единицы подписчиков, публикаций нет
около года. Вывод в отчёте: это не спад, а остановка; аудитория не потрачена, KPI
задаются с нуля.

### 3. Стратегия и контент-план

- выбор каналов с обоснованием и отказом от площадок, недоступных в РФ;
- четыре портрета аудитории вокруг маржинальных услуг, язык клиента, обещание, возражение и ответ;
- рубрикатор на 10 рубрик с пропорцией месяца 70 / 20 / 10;
- календарь на 28 дней: 28 авторских единиц, 73 публикации с учётом кросспостинга;
- юридические ограничения на рекламу юруслуг вынесены в отдельный блок, дисклеймер обязателен
  в каждом посте с призывом к действию;
- план первых семи дней, критерий недели и границы: что SMM не может сделать без бюджета,
  съёмки и разработчиков.

## Стек

Серверный HTML через `curl`, краул `sitemap.xml`, Chrome DevTools Protocol
для замеров, Schema.org / JSON-LD, Open Graph, Core Web Vitals, веб-аналитика, контент-маркетинг,
Telegram, VK, MAX, Rutube, UTM-разметка. Название CMS объекта аудита в публичной версии не
приводится.
